# 方法、输出字段与适用范围

## 输出里看什么

| 文件 | 内容和用途 |
|---|---|
| `octahedra.csv` | 每个 Ni 的配位数、顶点轴倾角、两种侧视投影的有符号倾角、三维旋转向量、拟合残差及警告 |
| `analysis.json` | 完整结果；含源文件 SHA-256、晶格、参考坐标、每个 O 邻居的原子编号和周期平移、旋转矩阵与参数 |
| `tilt_yz.png` / `.svg` | 沿层坐标 x 方向的真实 Ni—O 键投影；红色为顶点轴顺时针、蓝色为逆时针，附逐 Ni 编号 |
| `tilt_xz.png` / `.svg` | 投影到层坐标 xz 平面的真实 Ni—O 键，屏幕横轴为 +x、纵轴为 +z |
| `layers.csv` | 自动分层及层内倾角统计；**不可只看带符号均值，正负可能抵消** |
| `bridges.csv` | 确实共享 O 的 Ni—O—Ni 键角，区分面内与层间桥 |
| `interlayer_pairs.csv` | 相邻 Ni 层的最近面内配准候选，保留并列候选、周期像，以及同向/反向/近零/未定关系 |

`same`/`opposite` 是指定坐标分量或指定投影下的符号关系；**不是自动的 Glazer `+`/`−`**。`unbridged_candidate` 仅表示这对 Ni 没有找到共同配位 O，不能对任何结构都自动解释为岩盐层。缺氧、配位识别失败也可能产生这一标签。晶体相及空间群不由本程序判定。

## 我们怎样把论文里的描述转为可算的量

1. Chen 等，*Advanced Materials* **37**, e04238 (2025)，DOI [10.1002/adma.202504238](https://doi.org/10.1002/adma.202504238)：正文第2页 §2.1 明确写常压 La₃Ni₂O₇ 的 `a⁻a⁻c⁰`（Glazer）倾转。第3页 Fig.2/§2.2 和第4页 Fig.3/§2.3 比较沿 [100] 观察时跨岩盐层的平行/反平行倾转。图3的 `h` 是面内氧跨岩盐层的距离，不是倾角。
2. Dong 等，*Nature Materials* (2025)，DOI [10.1038/s41563-025-02351-2](https://doi.org/10.1038/s41563-025-02351-2)：所给 PDF 第4页 Fig.3 用红/蓝菱形表示顺/逆时针倾转；正文区分 RP 双层内部的反向倾转与加氧后跨双层排列的改变。第5页区分 stage-1、period b 与 period 2b。**该文不是给出一个可直接调用的 POSCAR 倾角算法**。
3. Glazer 的三字母描述参考赝立方三轴的转动幅度关系，上标描述沿相应轴相邻八面体转动的同相、反相或零转动。它描述的是协同排列，不能由一个 Ni 的角度或一个全胞平均值独立确定。畸变八面体的转动/形变分解也依赖定义，参见 [IUCr 的几何分析论文](https://journals.iucr.org/b/issues/2022/01/00/ra5104/index.html)。

**本工具自己的实现**是周期邻居识别、带符号顶点轴测量、六键方向的最佳刚体拟合、共享氧拓扑和逐层配准记录；这些公式不是冒称来自上述两篇文章的原始程序。它输出判断文献倾转模式所需的几何证据，不强行给每个缺陷超胞指定一个空间群或 Glazer 记号。

两篇文章对象不同（La₃Ni₂O₇ 系列与 La₂PrNi₂O₇₊δ），加氧相分别讨论 P2/m 与 B2em；不能把它们当成我们的所有构型都必须满足的同一个结构模型。第二篇的部分占位/条纹无序，也不能由一个有序小晶胞完全代表。

## 角度的严格定义

假设 **a、b 张成层面，c 为堆垛方向**。右手正交坐标：

- x = a / |a|；z = (a × b) / |a × b|；y = z × x。
- 非正交晶胞中 y 不严格等于 b，z 不严格等于 c；程序记录实际坐标矩阵。
- 参考面内键轴 u = cosφ x + sinφ y，v = −sinφ x + cosφ y。`--azimuth` 是 φ。φ=45° 对应本批常规 Amam 晶胞中的对角 Ni—O 方向。

在周期边界下选取截止半径内的 O。仅有且恰好有6个候选时才拟合；同一 O 的不同周期像分别保留。利用与参考 ±u、±v、±z 的方向匹配确定六个方向标签。

**顶点轴**：n = normalize(r(O上) − r(O下))，使它对应参考 +z。

- 三维顶点轴倾角 θ = arccos(n·z)，非负。
- yz 侧视角 α = atan2(n·y, n·z)，换算为度。图上 +y 向右、+z 向上；顶点轴上端向右为**正，顺时针**。绕 +x 的右手正转会使该投影角为负。
- xz 侧视角 β = atan2(n·x, n·z)。二维投影角不是三维总倾角。
- 两张图仅以一个度数标注上述 α / β，显示两位小数，颜色按当前投影角编码。轮廓为实际六个氧投影的凸包，半透明填充内叠加真实 Ni—O 键线。图中不画 z 参考虚线或角弧，不标三维 θ；θ 保留在数据文件中。零投影不表示零三维倾角。无有效 NiO₆ 拟合时显示灰色键线和 N/A，不构造完整八面体轮廓。
- 顶点轴用 O—O 连线而非单根 Ni—O；如果 Ni 偏心，两根顶点 Ni—O 并非共线。因此它和六键整体拟合可以不同。

**六键刚体拟合**：将六根 Ni—O 键归一化，等权求使 Σ|R·eᵢ − dᵢ|² 最小的 proper rotation（det R = +1）。SVD 求解；R 是将参考方向映射到实际方向的主动旋转矩阵。

- `omega_x/y/z_deg` = log(R) 的轴角旋转向量分量，使用层坐标。
- `omega_pc_x/y/z_deg` 将同一向量投影到 u、v、z 参考轴。
- **这些分量不是三个有限角 Euler 旋转，也不直接等于某文献的 Glazer 幅度**。小转角时可作为各轴转动强度的局域描述。
- `fit_rms_deg` 是六根实际键方向与刚体拟合方向的角残差 RMS；它描述非刚性偏离或参考/配位问题，**不是倾角统计误差条**。
- `bond_distortion` = 六根键长的 mean[(l/mean(l)−1)²]，记录在 JSON；键长变化与转动分开描述。

`bridges.csv` 的 θ(Ni—O—Ni) 直接由真实三维向量计算。**(180°−桥角)/2 只有在特定对称、等幅反向转动情况下才等于单个八面体倾角**，本工具不采用它作为通用替代。

## 分层、层间关系与限制

按 fractional c 对 Ni 分层，使用层法向距离阈值并处理跨晶胞边界的层。层号随原点改变，不是物理不变量。对相邻层，记录所有与最小面内位移相差≤0.02 Å的配准候选，包括周期边界等距候选；不会任意挑一个再据此声称层间翻转。`registry_candidate_count>1` 时尤其需要结合投影、宿主参考和晶体学平移确定比较对象。

默认符号判据：两个角绝对值都≥0.5°时才判同/反向；否则 `near_zero`。对称性稍破缺、超胞旋转或强翘曲时，应核对坐标、分层和配准，不应只数同向/反向行数。

局域几何已支持非正交晶胞；层间配准候选枚举面向本项目常规/√2晶胞，极度剪切或非约化晶格需先规范基矢并核查候选，不承诺任意病态晶格的全局穷举。若层面不是 ab，需先有记录地重排结构基矢，而不是直接使用默认分层。

可调参数：

```text
--cutoff 2.6             Ni—O配位截止半径，Å
--search-radius 4.2      搜索半径，须大于cutoff；用于第7邻居诊断
--layer-tol 0.6          Ni层法向聚类阈值，Å
--sign-threshold 0.5     同/反向判定的近零门槛，度
--exclude-o 49,50        明确排除的O原子编号；只在确知宿主映射时使用
--no-plot               仅生成CSV/JSON
```

不根据“末尾几个 O”自动认定间隙氧。少于6配位或多于6配位时不给刚体角；可先查看真实邻居、截止半径和配位改变。若人为排除近邻间隙氧，应同时保留未排除时的配位事实，避免掩盖真实 NiO₇ 等变化。

当第6/7邻居相隔<0.15 Å、最远配位键接近截止值0.1 Å、拟合 RMS>5°、最大拟合偏差>15°或总转角>35°时给出诊断警告。这些是程序工作阈值，不是材料普适定律或几何收敛标准。对于大转角/多畴，参考轴匹配可有八面体对称等价歧义，需显式参考对应。

程序不能凭 POSCAR 判断 U、磁性、压力、总能是否可信或结构是否已弛豫收敛，也不能从一个静态结构证明超导机制。
